# HirePulse HK 職脈直聘 — Job-Finding & Headhunter Platform Demo

A Hong Kong bilingual (`繁體中文 / English`) job-finding and executive headhunting platform demo featuring **both a Desktop Website version and an interactive Mobile App version** sharing synchronized live state.

- **Live Demo (GitHub Pages):** https://jackyabsee.github.io/hirepulse-hk-demo/
- **Repository:** https://github.com/jackyabsee/hirepulse-hk-demo

## Key Features
- **3 Presentation Modes:** Switch seamlessly between **Website (`🌐 網站版`)**, **Mobile App (`📱 手機 App 版` iPhone 16 Pro / Android / Fullscreen)**, and **Web + App Split Sync (`⚡ 雙屏同步演示`)**.
- **Direct Boss & Headhunter Chat:** Real-time simulated chat threads with stage tracking (`新招呼` → `溝通中` → `已發送履歷` → `面試邀約`), 1-click PDF CV sending, interview booking cards, and candidate/recruiter reply toggle.
- **Smart CV Auto-Parsing:** Upload a resume or run the 1-click AI sample parse to discover work experience and boost job match scores across both Web and Mobile App.
- **Headhunter & Employer Ad Console:** Publish Diamond/Gold sponsored job ads and boost listings live across both Website and Mobile App.
- **Customizable Non-Green Palettes:** Switch between **Royal Indigo (`#4F46E5`) + Warm Coral (`#F97316`)**, **Ocean Sapphire**, and **Crimson Luxe**.
